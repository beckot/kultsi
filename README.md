# Kultsi

Tämä repository kokoaa **Kultarinnantie 20 A** -asuntoon liittyvät avoimet asiat, selvitykset ja pienet miniprojektit yhteen paikkaan.

## Toimintamalli

- `main` kuvaa pysyvän, yleisen tilannekuvan.
- Rajatut selvitykset ja muut miniprojektit tehdään omilla brancheillaan.
- GitHubissa säilytetään päätökset, havainnot, avoimet kysymykset ja toimenpiteet.
- Varsinaiset talon tekniset PDF:t, sopimukset, kuvat ja muu alkuperäisaineisto säilytetään Google Drivessa eikä niitä lähtökohtaisesti kopioida tähän repoon.

## Aktiiviset kokonaisuudet

Miniprojektit näkyvät erillisinä brancheina ja tarvittaessa pull requesteina.
